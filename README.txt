Leaderboards site for Mutant Fridge Mayhem PC Port.

To deploy:
1. Push this folder to a GitHub repo
2. Enable GitHub Pages (Settings > Pages > Source: main branch)
3. Your site will be at https://yourusername.github.io/repo-name/

Or use any static hosting (Netlify, Vercel, Cloudflare Pages).

Before going live:
1. Replace "Icon" placeholder with icon.png
2. Replace "Game Logo" placeholder with banner.png
3. Update API_URL in index.html with your Cloudflare Worker URL
